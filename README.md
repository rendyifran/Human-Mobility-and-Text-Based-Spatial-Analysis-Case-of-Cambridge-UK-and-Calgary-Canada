# Human Mobility and Text Based Spatial Analysis: Case of Cambridge,UK and Calgary,Canada
Mobility and textual data analysis using mobility datasets from Gowalla in Cambridge and amenity review texts from Calgary, Canada

Many contemporary datasets include links between geographic locations and natural language texts, commonly referred to as geotext data. The rise of social media platforms has significantly contributed to the growth of this data type, as users often share content tagged with location information. Such data offers valuable insights into human mobility patterns as well as public perceptions and opinions about specific places. These insights can inform urban planning efforts, contributing to more effective infrastructure design, equitable resource distribution, and overall improvements in city development. In this study, the author contributes by outlining techniques for analyzing mobility and textual data, using mobility datasets from Gowalla in Cambridge and amenity review texts from Calgary, Canada, to inform future research.
